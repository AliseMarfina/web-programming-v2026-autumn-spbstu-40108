# Лабораторная работа 4

## Задание

Вариант 22. Управление мероприятиями (Event). Требования:

1. Создать класс `Event` с полями: `id`, `title`, `participants`, `date`.
2. Реализовать методы: `addParticipant`, `removeParticipant`, геттер
   `participantCount`.
3. Реализовать 5 функций работы с коллекцией: группировка по дате, уникальные
   участники, группировка по количеству участников, поиск по участнику, поиск по
   месяцу.
4. Реализовать UI с карточками, формами добавления/удаления, асинхронными
   операциями (Promise + setTimeout) и сохранением в localStorage.

## Реализация

- `model.js`: Экспортирует класс `Event` (PascalCase) и 5 именованных функций
  для работы с коллекцией.
- `main.js`: Точка входа. Управляет рендерингом, обрабатывает формы, выполняет
  асинхронные операции через `Promise` + `setTimeout` и синхронизирует состояние
  с `localStorage`.
- `index.html`: Разметка с соблюдением DOM-контракта (`data-testid` и атрибуты
  `name`).
- `styles.css`: Базовые стили для форм и карточек.

## Запуск

Откройте `index.html` в браузере.
