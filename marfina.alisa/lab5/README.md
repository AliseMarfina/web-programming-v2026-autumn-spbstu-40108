# Лабораторная работа 5

## Задание

Вариант 22 Игра "Крестики-нолики"

## Реализация

Приложение написано на React с использованием сборщика Vite. Реализованы экраны:
заставка, выбор режима, игровое поле, экран завершения. Игровой процесс
поддерживает режимы PvP и PvC. Используются data-testid для автоматического
тестирования (game-board, game-cell, game-restart).

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
